WATAER MELON

팀원 이름 | 채준호, 박지현, 조민웅

프로젝트 기간 | 2024. 09. 27.~ 2024. 09. 31.

프로젝트 소개 |

📌 WATER MELON(워터멜론)은 리스너와 제작자를 이어주는 무료 음원 공유 서비스 플랫폼입니다. 

📌 플랫폼의 주요 클라이언트는 컨텐츠 제공자 '크리에이터' 와 컨텐츠 사용자인 '회원' 입니다. 

📌 사용자는 업로드 된 음원을 웹 뮤직 플레이어에서 스트리밍 방식을 통해 재생할 수 있으며, 나만의 플레이리스트를 공유할 수 있습니다.

📌 크리에이터는 음원 메타 데이터와 원본 파일을 서버에 업로드할 수 있으며, 등록된 메타데이터는 MySQL DBMS를 통해 관리됩니다.


✨ 개발 언어 및 프레임워크
Java, Servlet/JSP, HTML/CSS, NCS, Ajax, MyBatis, JDBC, Git, Spring
